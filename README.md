Disk Forensics and Timeline Reconstruction Using Autopsy/Sleuth Kit

Project Summary

This project involved performing disk forensic analysis and timeline reconstruction using Autopsy and The Sleuth Kit. A Windows 10 virtual machine was used to simulate user activities, including file creation, downloads, browsing, file deletion, and other system activities.

A forensic image was created using FTK Imager and analyzed in Autopsy to recover deleted files, examine system artifacts, and reconstruct user activities through timeline analysis.

Tools Used

• Autopsy 4.23.1 – Used for disk analysis and timeline reconstruction.

• The Sleuth Kit – Used as the forensic analysis framework behind Autopsy.

• FTK Imager 3.3.0 – Used for forensic image acquisition.

• VMware Workstation Pro – Used to create and manage the virtual machine environment.

• Windows 10 Virtual Machine – Used as the investigation target.

How to Run the Project

1. Perform simulated user activities on the Windows 10 Virtual Machine.

2. Create a forensic image of the system using FTK Imager.

3. Import the forensic image into Autopsy.

4. Analyze important artifacts such as:
   • Deleted Files
   • Browser History
   • Recent Documents
   • Downloads
   • USB Devices
   • Timeline Events

5. Document findings and reconstruct the sequence of user activities.
